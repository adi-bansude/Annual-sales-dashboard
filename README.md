Annual Sales Dashboard

📊 Project Overview

An interactive Annual Sales Dashboard created using Microsoft Excel to analyze sales performance and identify important business trends and insights.

The dashboard transforms raw sales data into meaningful visualizations and key performance indicators, making it easier to understand overall business performance.

🛠️ Tools Used

* Microsoft Excel
* Pivot Tables
* Pivot Charts
* Slicers & Filters
* Data Cleaning
* Data Analysis

📈 Dashboard Features

* Total Sales Analysis
* Total Orders Analysis
* Orders vs Sales Analysis
* Interactive Slicers & Filters
* Sales Performance Analysis
* Visual Charts and KPIs

📂 Files Included

* Sales Report.xlsx – Raw sales data and interactive Excel dashboard
* Dashboard.png – Preview of the final dashboard

💡 Key Insights

The dashboard helps identify:

* Overall sales performance
* Order trends
* Sales patterns
* Performance across different categories/segments
* Business trends using interactive filters

🎯 Objective

The objective of this project is to demonstrate practical skills in Excel data analysis, dashboard creation, data visualization, and business reporting using real-world sales data.
